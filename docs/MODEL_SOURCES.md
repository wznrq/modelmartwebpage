## 数据整理说明

### 官方核验状态（2026-04-24）
- `src/data/models.ts` 是系统展示数据，不代表每个型号都已在官方模型页出现。
- `docs/MODEL_DATA_REFERENCE.md` 已记录 OpenAI、Anthropic、Google、Mistral、xAI、DeepSeek、Perplexity 等型号/计费口径的核验和修正结果。
- 云平台托管模型（AWS Bedrock、Azure OpenAI）按平台可用性和区域价格核验，不能和基础模型厂商 API 价格混用。
- 图片、视频、搜索类模型常见计费单位不是纯 token，展示为 CNY 时必须说明是归一化估算。

### 价格换算
- 数据价格以 **人民币 (CNY)** 为单位存储
- 国际模型按汇率 **1 USD ≈ 7.2 CNY** 换算（2026年5月沿用）
- 实际收费以各平台官方定价为准

### 更新频率
- 建议每季度更新一次定价信息
- 关注各厂商官方公告获取最新价格变动

### 数据准确性
- 价格信息基于公开资料整理
- 如发现数据有误，请提交 Issue 或 Pull Request

- ✅ 已验证 - 链接有效且包含定价信息
