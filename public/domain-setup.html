🎉 ModelMart 部署成功!

最后一步: 绑定自定义域名 modelmart.ai

✅ 已部署到 Cloudflare Pages
当前可用地址:
https://modelmart.pages.dev
1 访问 Pages 设置页面

点击下方按钮打开 Cloudflare Dashboard:

🚀 打开域名设置页面
2 添加自定义域名
  • 点击页面上的 "Set up a custom domain" 按钮
  • 在输入框中输入: modelmart.ai
  • 点击 "Continue"
  • 确认域名信息,点击 "Activate domain"
3 等待 DNS 传播

Cloudflare 会自动配置 DNS 记录和 SSL 证书。

⏱️ 预计时间: 通常在 1-5 分钟内生效,最长可能需要 24 小时。

您可以通过以下方式验证:

# 在终端运行 nslookup modelmart.ai # 或使用在线工具 https://www.whatsmydns.net/#A/modelmart.ai
4 验证域名

配置完成后,访问以下地址测试:

  • ✅ https://modelmart.ai
  • ✅ https://www.modelmart.ai
💡 提示: 如果看到旧内容,请清除浏览器缓存或使用无痕模式访问。
❓ 域名还未添加到 Cloudflare?

如果 modelmart.ai 还未添加到您的 Cloudflare 账户:

  1. 访问 Cloudflare Dashboard
  2. 点击 "Add a Domain"
  3. 输入: modelmart.ai
  4. 按照指示更新域名的 Nameservers
  5. 等待 DNS 传播 (最多 24 小时)
  6. 然后回到步骤 1 继续绑定
